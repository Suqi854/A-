# A股行情连接

本包通过 `.app.json` 引用已有行情 App。先使用该 App 的 `get_diagnostics`
（保持 `probe:false`）核对连接与可用工具。找不到工具或出现登录、连接、权限提示时，
说明尚未完成连接并停止依赖该连接的操作；Git 安装不会自动授予私有 App 的权限。

用户请求行情时，使用 App 实际提供的 `get_quotes` 或 `get_bars` 等只读工具，
严格遵循工具输入约束。按返回结果说明提供方、源时间、读取时间、时效和异常。
缺数或过期时直说，不把最近时段快照称为实时行情，不编造价格，不把分钟观察当逐笔成交。

连接验收只需一次不探测上游的诊断，以及用户需要时一次有明确标的的只读行情调用。
不启动后台采集、自动运行、交易或账本写入。本包不包含账户、策略或研究技能。
