# 个股研究展示组件

这个目录提取已有应用中可独立复用的展示代码与纯函数。包含诊断弹层、展开快览、图层开关、历史研究事件详情及价格参考绘制。它不包含应用、账户、行情提供方、筛选策略、信号引擎或交易接口。

## 文件与出处

- `quote-capture-preference.mjs`：原项目的版本化偏好模块。旧默认关闭迁移为开启，用户明确暂停保留；仅保存开关意图，不创建采集任务。
- `rolling-chart-references.mjs`：从原研究模块提取的 `rollingChartReferences` 与两个纯辅助函数。最近20个观察价或20根已完成分钟K线的高低区间，是方法性参考，不是买卖策略。
- `stock-diagnosis-ui.mjs`：原项目的展示与绘图控制器；原先直接导入的三个计算函数改为强制依赖注入。其余展示行为保留。
- `*.test.mjs`：独立合成输入测试，不含实际证券、行情或用户记录。

以上为原项目自有代码的提取和适配，没有复制第三方框架、参考站源码或完整风险模型。不将通用滚动极值计算归称某个外部开源策略，也不宣称采用未实际接入的开源模块。本目录不新增或变更仓库的许可授权；使用和再分发时须另行确认适用许可。

## 测试

在本目录执行 `node --test *.test.mjs`，无需安装依赖。覆盖偏好迁移与持久化失败、因果前缀、不完整/乱序数据、输入口径、展示依赖注入、首次空数据和HTML转义。DOM测试使用小型合成宿主；不代表完整应用的浏览器或生产验收。

## 使用边界

`createQuoteCapturePreference(storage)` 接受与浏览器 Storage 相同的 `getItem/setItem` 接口。`enabled` 只是期望状态，`persisted` 明确存储是否成功。调用方负责请求周期、交易时段、单实例、退避、停止和源时间；开启偏好不等于源数据每秒更新，也不启动分析、提醒或交易。

`rollingChartReferences({symbol, source, adjustment, kind, interval, rows})` 只接受不复权及 `intraday/1m/5m`。分时输入用 `price`，K线输入用 `low/high` 且 `complete=true`；每行需严格递增的 `source_timestamp`。不足20行、重复时间、坏价格或未完成K线返回局部不可用，未知强度不填默认分。每个参考值只使用该行及之前19行；以后极值不回画到更早时刻。调用方仍需保证证券身份、交易日、来源和可知时间可信。
